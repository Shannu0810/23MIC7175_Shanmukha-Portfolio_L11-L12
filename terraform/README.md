# Terraform Infrastructure as Code (IaC)

This directory manages the Kubernetes resources for the portfolio infrastructure declaratively.

## 🚀 Usage

### 1. Initialize Providers
```bash
cd terraform
terraform init
```

### 2. Review Execution Plan
```bash
terraform plan
```

### 3. Apply Infrastructure
```bash
terraform apply -auto-approve
```

### 4. Teardown
```bash
terraform destroy
```
